# Preflight checklist

Run before writing any code. If any box is unchecked, stop and report what is
missing.

- [ ] I have read CONTRIBUTING.md and the PR template for this repo.
- [ ] I know the repo's license and that protobom's license is compatible.
- [ ] I am not adding a mandatory dependency.
- [ ] The flag is opt-in and off by default.
- [ ] I have a test that fails without my change and passes with it.
- [ ] I have listed every NTIA field I cannot populate, with a reason.
- [ ] The diff contains no unrelated changes.

# PR prompt

```
Write the PR for <repo> from the branch `sbom-support`.

PR description must contain:
- Motivation: cite NTIA minimum elements, EO 14028, EU CRA.
- Design: the integration point and why it is the cheapest hook.
- Alternatives considered (including SPDX/CycloneDX JSON fallback).
- Test plan: exact commands, and what the test asserts.
- Backwards-compatibility note: flag is opt-in, off by default, no new
  mandatory dependency.
- Gaps: every NTIA field the build system cannot supply, with a reason.

Title: `Add opt-in SBOM generation (<flag name>)`

Do not open the PR. Save the title and body to `pr/<repo>.md` and wait for
approval.
```
